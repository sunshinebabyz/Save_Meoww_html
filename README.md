
# 🐱 Save Meow (https://2256210028.netlify.app/)

A responsive pet shop and cat adoption website built with **HTML, CSS, and JavaScript**.

Save Meow is a front-end web project designed to provide pet owners with a simple platform to explore pet products, manage a shopping cart, place orders, and discover cats available for adoption.

---

## 📌 Project Overview

Save Meow combines two main purposes:

- 🛍️ Pet product shopping
- 🐱 Cat adoption

The website provides a multi-page interface with product browsing, search, shopping cart, checkout, login/registration, and cat adoption features.

---

## ✨ Features

### 🏠 Homepage

The homepage provides:

- Store introduction
- Promotional slider
- Featured information
- Pet care content
- Nutrition information
- Cat adoption information
- Product highlights
- Responsive navigation

- Address

- Subtotal

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Open the project

Navigate to the project folder:

```bash
cd Save_Meoww_html
```

### 3. Run the website

Open:

```text
index.html
```

in a web browser.

You can also use **Visual Studio Code + Live Server** for a better development experience.
